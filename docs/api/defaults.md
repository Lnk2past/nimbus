# Defaults

The `nimbus.defaults` object controls the fallback values used by all `TransitionPipe` instances that do not set their own params explicitly.

```python
import nimbus

nimbus.defaults.duration_ms = 600
nimbus.defaults.easing = "elastic_out"
```

::: nimbus.defaults._Defaults
    options:
      show_root_heading: false
